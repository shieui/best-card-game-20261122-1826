**Emberfall — Duel of the Four Winds**: an original turn-based card battler. You are the Ember Warden, duelling Wren the Gale across a lantern-lit table with a deck of wind-spirits — Flame, Tide, Leaf and Stone, each told apart by colour and glyph. Spend mana, play spirits, and strike her 30 life to zero before she strikes yours. Playing two spirits of the same wind in one turn raises a **Wind Surge** (+2 damage), so sequencing a hand matters more than dumping it. The rival reads the table — she strikes for lethal, guards when hurt, and draws to keep her options open — so her choices can be read and countered. Title screen, live table with both hands, readable costs and values, life and ward totals, and win/loss screens; keyboard (1–7, Enter, E, R) and mouse. Static files only — no build step, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Or serve `game/` with any static HTTP server and open `game/index.html`.
